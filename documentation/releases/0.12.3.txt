# 변경 이력

## 0.12.3 로컬 후보

- Vue 3용 패키지 이름을 `solyi-ui`로 통일하고 `@solyi/core`와 두 tarball 설치를 검증합니다. S 컴포넌트 이름은 유지합니다.
- 공통 선택 행과 Warm Sand의 selected 색 역할을 제공하고, 기존 Violet/Sage 색 값은 유지합니다.
- 컴포넌트 Examples/API 탭·접힌 코드와 공유 헤더 설정, starter 초기 로딩·실패 복구를 정리합니다.
- 공개 푸시·npm 게시·1.0.0은 하지 않습니다. 앞서 고정한 로컬 후보와 기존 릴리스의 바이트를 보존합니다.

## 0.12.0 로컬 후보

- 임시 UI 패키지 이름 @solyi/vue-ui를 선택한 이름 solyi-ui로 변경합니다. Vue 3용 라이브러리이며 S 컴포넌트·props·events는 그대로입니다.
- Core 이름 @solyi/core는 유지합니다. 과거 이름의 고정 파일과 이력도 보존합니다.
- 현재 로컬 tarball 설치를 검증하며 npm 이름 확보·게시·1.0.0 출시는 수행하지 않습니다.

## 버전과 폐기

Patch는 계약을 유지하는 수정, Minor는 새 기능과 문서의 확장입니다. 계약을 깨는 변경은 별도 이행 안내가 필요합니다. 0.x에서도 폐기 표기·대체 예시·이행 방법을 먼저 제공하고 최소 다음 minor까지 병행합니다. 이후 제거 시 변경 이력에 정확한 버전과 영향을 기록합니다. 현재 폐기 예정 API는 없습니다. 기존 앱의 운영 반영은 별도 검토와 승인 범위입니다.
