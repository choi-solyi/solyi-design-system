| 역할 | 기존 라이트 | 새 라이트 | 기존 다크 | 새 다크 |
|---|---|---|---|---|
| canvas | #F8F4EE | #F6F0E8 | #231D19 | #211B17 |
| surface | #FFFDFA | #FFFDFA | #2E2721 | #302720 |
| selected-surface | 전용 역할 없음 | #E8D2BC | 전용 역할 없음 | #543E2E |
| selected-text | 전용 역할 없음 | #4A3020 | 전용 역할 없음 | #FFF1E4 |

강조 바탕 `accent-soft`는 유지하고 선택 의미를 분리합니다. Violet/Sage는 기존 20개 역할의 값을 그대로 유지하며 새 역할은 기존 accent-soft/text/accent에서 가져옵니다. UI 색 역할은 테마당 24개입니다.

## 계산 검증

| 조합 | 라이트 | 다크 |
|---|---|---|
| 선택 글자 / 선택 배경 | 8.287:1 | 9.002:1 |
| 선택 테두리 / 선택 배경 | 3.650:1 | 5.142:1 |
| 선택 테두리 / 일반 카드 | 5.251:1 | 7.535:1 |
| 선택 표시선 / 선택 배경 | 4.475:1 | 6.415:1 |
| focus / 선택 배경 | 3.769:1 | 6.308:1 |
| 선택 배경 / 일반 카드 | 1.439:1 | 1.465:1 |

배경끼리 3:1이라고 주장하지 않습니다. 선택을 식별하는 테두리·표시선 및 체크와 상태 계약을 함께 사용합니다. 일반 카드의 장식 테두리에 3:1을 강제하지 않습니다. 이 비율 계산은 전체 WCAG 적합성 인증이 아닙니다.

## 적용 범위

Core 선택 행·선택 표 행·모바일 카드·트리·탭·자동완성, Vue 라디오 카드·분할 선택·다중 선택·표와 문서의 선택 탐색에 연결합니다. 행의 보조 글자도 선택 전경을 상속하여 낮은 대비가 남지 않게 합니다. 기본 체크박스 자체에 여백을 주지 않습니다.

다른 소비 프로젝트의 `.current`/`.viewed` 로직·파일·서버는 수정하지 않습니다. 기존 앱이 `accent-soft`를 직접 쓰는 경우 새 selected 역할 매핑과 앱의 상태 구분은 해당 프로젝트에서 별도로 적용해야 합니다.
