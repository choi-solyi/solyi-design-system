# 0.11.1 AI guide 검수

소비 프로젝트 DESIGN.md 한 원본에서 사이트 HTML·짧은 프롬프트·복사 데이터·다운로드·두 패키지 포함 파일을 생성합니다. 문서0.11.1, Core0.4.4, Vue UI0.9.1이며 컴포넌트 동작과 디자인 토큰 값은 변경하지 않았습니다. 과거 산출물은 보존합니다.

## 확인한 범위

- 가이드에 등장하는 S 컴포넌트 이름을 실제38개 API와 대조했습니다. 역할 토큰·폰트·반경·테마·밀도·자동 import·SForm/rules·서버 오류·공개 초점 메서드·프로젝트별 예외를 현행 계약에 맞췄습니다. 파일명만으로 모든 AI가 자동으로 읽는다고 안내하지 않습니다.
- 두 tarball의 실제 파일 목록과 두 독립 소비 앱에 설치된 DESIGN.md 바이트가 루트 원본과 일치합니다. static export, 타입·빌드·peer 외부화·파일·폰트 라이선스 검사를 통과했습니다. 30개 샘플의 타입 검사와 실제 패키지 소비 앱 빌드를 통과했습니다.
- 정적 원본·화면 데이터·다운로드·복사 문자열의 일치, 시작 프롬프트 추출, Markdown HTML escaping, 공개 파일 allowlist·출처 해시, 메뉴96개 링크·검색106개 목적지·기존 링크·설정 복원을 검사했습니다. 저장소 문서 링크 검사도 통과했습니다.
- 실제 Google Chrome155.0.8059.85 / Playwright Core1.64.1의 격리 headless 컨텍스트를 사용했습니다. 사용자 프로필·사용자 파일·OS 설정은 사용하지 않았습니다. 1180·720·333 CSSpx × light/dark에서 가이드 기본 화면6장과 대표 펼침 화면을 직접 읽었습니다. 새 영역의 잘림·겹침·본문 가로 넘침을 발견하지 못했습니다. 모든 문서 전체의 시각 보증은 아닙니다.
- 실제 clipboard의 가이드·프롬프트 원문 일치(Windows CRLF만 정규화), 격리 Chrome 임시 다운로드 파일의 이름·내용 일치, Enter로 전체 읽기 펼침, DESIGN.md 검색 후 앵커 이동, 작은 화면 메뉴 선택 후 닫힘을 통과했습니다. 다운로드는 사용자 기본 다운로드 폴더를 검수한 것이 아닙니다.
- 검수 서버의 Windows 경로 끝 구분자 중복으로 첫 요청이403을 반환한 테스트 도구 오류를 수정했습니다. 정상 경로에서 여섯 조합 검사가 통과했습니다. 제품 코드를 우회하거나 보안 설정을 바꾸지 않았습니다.
- 도메인 담당 작업에서 대표 주소 연결 완료를 전달받아 현재 안내·설치 명령·공개 검증 기준을 ui.solyi.kr로 정리했습니다. 여기서는 DNS·Pages·Netlify 설정을 변경하지 않았습니다. 기존 GitHub 다운로드와 과거 release 파일은 보존합니다.
