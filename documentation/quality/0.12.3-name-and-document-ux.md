# 패키지 이름·공통 선택·문서 UX 로컬 검수

2026-10-23 UTC. 후보는 문서 **0.12.3 / @solyi/core 0.4.9 / solyi-ui 0.10.3**입니다. 이 기록은 로컬 검증이며 공개 푸시·CI·Pages 성공을 뜻하지 않습니다. 현재 공개본은 0.11.2입니다. npm 게시·계정 설정·1.0.0·역사 파일 삭제를 하지 않습니다.

## 변경 범위

- Vue 3 UI 이름을 `solyi-ui`로 정리했습니다. S 공개 API 이름은 그대로이고 Core 이름은 `@solyi/core`입니다. 현재 코드·타입·스타일 import, 전역 등록, 샘플, DESIGN.md·AI guide·설치·빌드 도구를 실제 이름과 맞췄습니다. 과거 tarball은 변경하지 않았습니다.
- Core의 선택적 `.sol-choice-row`가 8px 세로 / 12px 가로 inset과 최소 44px 행을 담당합니다. 목표 목록과 체크·라디오 목록에 적용하며 일반 checkbox 자체나 이미 16px inset인 카드형 라디오에 중복 여백을 넣지 않았습니다. 목표 행은 단일 label로 전체 영역을 선택할 수 있습니다.
- Warm Sand의 선택 역할은 [별도 검수](0.12.2-warm-sand.md)에 실제 값·대비·범위를 기록했습니다. Violet/Sage 기존 색은 유지합니다. 공유 행·표·트리·탭 등에 적용하지만 다른 프로젝트의 `.viewed` 같은 로컬 클래스는 자동 수정하지 않습니다.
- 컴포넌트 38개는 Examples/API 실제 탭과 기본 Examples, 즉시 실행되는 실제 패키지 예제, 바로 아래 접힌 샘플 코드를 연결합니다. 원본 링크와 내부 구현 경고를 기본 화면에서 제거하고 기술 가이드의 Vuetify 안내·라이선스는 유지합니다.
- 문서와 starter가 같은 테마·밀도·모드 제어와 저장 resolver/CSS를 사용합니다. 기본↔컴팩트는 단일 스왑이며 실제 stack·카드 gap은 16px↔12px입니다. 버튼·필드 높이, 6/10/12/16px 반경과 폰트는 유지합니다.
- starter의 inline 초기 원형 로더는 실제 스타일 적용·앱 mount·폰트 준비를 기다립니다. 고정 최소 지연은 없으며 CSS/JS 실패·재시도, 폰트 폴백·noscript·축소 모션을 처리합니다.

## 실제 브라우저 확인

- 문서·starter 헤더와 Examples/API 최종6개 조합(1180·720·333px × light/dark)은 수정 후 모두 통과했습니다(05:54:37 UTC 완료). 직접 링크·뒤로/앞으로·키보드 탭·현재 원본 복사, 입력/노드/URL/스크롤 유지와 저장 복원, mode normal/hover/focus의4.5:1 이상 대비와 포커스 표시를 검사했습니다. 실제 좌표 클릭으로 테마·밀도·모드를 바꿔 Playwright의 자동 scrollIntoView와 제품 동작을 구분했습니다.

## 남은 결정과 한계

`solyi-ui`의 registry 이름 조회는 소유권 확보나 게시 성공을 보장하지 않습니다. npm 단독 설치는 `@solyi/core` 게시·스코프 권한 또는 승인된 의존 구조 결정이 먼저 필요합니다. 현재 두 tarball을 함께 설치하는 방식은 검증했습니다. 다른 앱 자동 업데이트는 연결하지 않았습니다.

실제 Safari·물리 Fold/터치·화면 낭독기·하드웨어 IME·400% 확대·forced colors·Core Web Vitals는 이번 환경에서 검증하지 않았습니다. 자동 대비·DOM 검사나 일부 스크린샷으로 WCAG 전체 준수, 모든 앱 호환 또는 모든 컴포넌트 상태의 시각 검수 완료를 주장하지 않습니다.
