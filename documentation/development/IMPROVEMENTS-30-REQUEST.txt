2. Components 페이지의 Button, Confirm Action, Icon Button의  Examples 구성이 동일해서 각 뭘 확인할 수있는건지 의미파악이 어려움.
Confirm Action 에서 `초안제거` 를 눌르면 버튼명이 바뀌고 한번 더 눌러야 처리가 되는 점은 이해했는데, 그외의 버튼들은 잘 모르겠어. ConfirmAction 에 해당하는것만 예제에 남겨줘. Icon Button 도 마찬가지야. 다 있을 필요 없는듯해 Badge, Chip, Icon 도 마찬가지.

3. Inputs - Autocomplete - 가상 분류 검색를 포커싱 해서 아래에 목록이나 검색결과가 없어요가 표시될때, `Autocomplete` 카드의 아래쪽에 공간이 생김. 닫으면 다시 사라짐. `Combobox` 의 blur 확정 사용은 포커싱 했을때 아래에 목록이 표시되어도 카드 하단에 여백이 생기지 않는 반면, `비동기 후보`를 눌렀을땐 또 여백이 추가되었다가, 포커스 아웃하면 여백이 기존대로 사라짐.

4. Date Picker 에서 `개발 설정 시연 (필수)` 이건 라디오로 선택할수있게 해줘.  
캘린더 버튼을 눌렀을때 팝업 표시 방법이 `모달 다이얼로그`일때와 `기존 기본 모달` 일때는 잘 표시가 되는데 `화면에 맞춰 자동전환`, `입력창에 연결된 팝업`을 선택하고 열면, 높이가 매우 작은 모달만 표시됨. 그리고 그 다이얼로그가 표시될때 또  하단부에 불필요한 여백이 생김.

5. Form - 입력과 검증복구 - 프로젝트 확인 누른 후 `검증 표시 지우기` 버튼을 눌렀을때 아무 액션이 업음

6. Multi Select 이것도 아래에 목록이 펼쳐질때, 그 부모 컴포넌트 영역 자체가 커지지 않았으면함 (불필요한 여백), 그리고 여러건 선택하면 현재는 입력칸 위쪽에 선택한 항목이 표시되고 있는데, 선택하면 입력칸 내에 칩형태로 표시되는게 더 자연스러울것 같음.

7. Number input 의 - 와 + 가 너무 멀리 떨어져 있어서 조작하기 불편함. 한쪽에 - + 둘다 있으면 좋겠음. Range Slider 의 `하한 직접 입력 (필수)` `상한 직접 입력 (필수)` 이부분도 - 입력칸 + 라서 불편함.

8. `Switch`와 `Radio Group` 의 구성이 동일해보이는데 어떤 차이가 있는건지 ..
radio group 에는 radio 만 두고, switch 에 단일체크 박스 형태랑 스위치 모양을 두는게 맞을거같아. 용어 및 태그를 통일해서 하나로 합치던가.

9. Text Field 의 `입력 로딩 표시` 는 의미를 모르겠음. 타이핑을 하던 말던 움직이지도 않고 그저 원모양의 뭔가가 추가되어있을뿐인데. 그리고 `입력 내부 X로 지운 횟수: 2` 이건 왜 카운트 하는거야 ? 뭐 어디 쓸데가 있는거면 둬..

10. Time Picker 의 `목록에서 시각 선택` 에 ↑ 화살표가 의미하는것이 무엇인지 파악하기 어려움. 선택후 위아래로 움직이면 되는건 알겠는데.. 아이콘으로 파악하긴 어려울듯.
그리고 `목록에서 시각 선택`에  X ↑ 아래방향 꺽쇠가 같이 있는것도 부자연 스러워.
시간 선택 부분에 있어서는 라벨을 시, 분을 위에 표시할게 아니라 각 입력칸의 오른쪽에 배치하는게 자연스러울것같아.
아니면 입력칸 내에 흐린 글씨로 `시`가 표시되게 하던가.

선택 완료도 오른쪽에 있으면 좋을것 같아. 추가로 `선택 완료` 버튼은 확인과 관련된 컬러가 입혀져 있으면 좋을것같아.

11. Accordion 의 예제가 지금은 1개뿐인데, 1개일때랑 여러개일때(3~5) 일때의 예제도 있으면 좋겠어 .

12. Breadcrumbs의 페이지수, 현재 페이지 양옆에 표시할 번호 수 부분도  - + 가 양 끝에 있어서 불편해.  그리고 맨 처음, 맨 끝으로 이동하는 버튼이  < > 를 그냥 두번 쓴거같은 < < > > 이거라 좀 못생겻어. 칸 크기는  > 이거랑 동일하게 하고 >>가 딱 붙어 있게 하던가 다른 아이콘을 쓰던가 해.
그리고 왜 Breadcrumbs 에 페이지네이션이 있는거지..? 페이지네이션 항목은 또 따로있는데 내용은 비슷해보이네. 동일하거나. Pagination 은 Pagination 쪽에만 옮겨줘. 반대로 기록함 / 기록 목록 같은 브레드 크럼은 브레드 크럼쪾에만 배치하고

13. Context Menu 의 `기본 동작 열기` 는 컨텍스트 메뉴 스럽지 않음. 클릭할 수 있는 요소인건 알겠지만뭐가 더 표시될거라는 느낌의 버튼 형태가 아님. 그리고, 눌렀을때 즉시 메뉴가 표시되는게 아니라 한번 그영역부분이 깜빡였다가 표시됨. 이것도 누르면 카드 자체의 하단부에 여백이 추가됨.
