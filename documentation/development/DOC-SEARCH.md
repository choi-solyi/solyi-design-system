# 문서 검색과 헤더 화면 설정

문서의 검색·메뉴·본문은 같은 목적지 카탈로그를 공유합니다. 목적지를 추가할 때 같은 카탈로그와 실제 본문 앵커를 함께 갱신합니다.

## 검색 계약

컴포넌트 이름·명시한 별칭·제목의 정확 일치를 설명·본문 매칭보다 우선합니다. 대소문자·전각 문자를 정규화하고 다중 단어는 모두 포함해야 합니다. Date Picker/날짜와 Time Picker/시간은 서로의 긴 설명보다 실제 컴포넌트 이름을 먼저 찾습니다. 사용자 입력 초안은 색인하거나 외부로 전송하지 않습니다.

입력에서 방향키/Tab으로 결과에 진입하고 결과에서 방향키·Home/End·Enter로 이동합니다. 입력의 Home/End 편집 동작과 IME 조합을 보존합니다. 초기화·결과 없음·Escape·초점 복귀를 함께 검사합니다. 결과는 기존 연속 본문의 실제 앵커이며 뒤로/앞으로와 새로고침 링크를 유지합니다.

## 헤더 설정 계약

테마는 Cool violet/violet, Quiet sage/sage, Warm sand/sand, 밀도는 comfortable/compact입니다. 이어진 라디오 그룹에 현재 테마 토큰의 색과 이름·선택 경계·체크를 함께 표시하여 색만으로 구분하지 않습니다.

작은 화면은 화면 설정 패널에 같은 컨트롤을 묶습니다. 라이트·다크 전환과 기존 저장·복원을 공유하고 저장이 제한돼도 현재 페이지에서 조작할 수 있습니다. 외부 서비스·새 권한·다른 앱 동기화는 추가하지 않습니다.

관련 원본은 `site/doc-search.js`, `site/topics.js`, `site/app.js`, `site/header-preferences.js`입니다. `scripts/doc-search-check.mjs`와 `scripts/header-preferences-check.mjs`에서 검색·설정 동작을 검사하고 실제 화면·기기 검수와 구분합니다.
