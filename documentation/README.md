# 저장소 상세 문서

사용자는 [처음 시작하기](guide/GETTING-STARTED.md)와 [설치·업데이트](guide/DISTRIBUTION.md)부터 읽습니다. 실제 컴포넌트의 Examples·Props·Slots·Events·Methods는 [문서 사이트](https://choi-solyi.github.io/solyi-design-system/#component)에 함께 있습니다.

- `guide/`: 설치·공통 계약·테마·언어·호환·브랜드·폰트
- `development/`: 소스 구조·문서 검색·재사용 전환 목록·이전 안내 원문
- `quality/`: 검증 결과·실제 화면 검수·확인하지 못한 환경
- `plans/`: 단계별 계획·당시 체크포인트와 현재 통합 완료표

`*-HISTORY.md`와 ‘이력 부록’은 당시 버전·미게시·미검수 상태를 보존한 기록입니다. 현재 지원 선언이나 현재 공개 상태로 읽지 않습니다. 최종 공개 상태는 정확한 SHA의 GitHub Actions와 공개 파일 확인 결과를 기준으로 합니다.

이전 루트 파일의 새 위치는 [문서 이동표](MOVED-DOCUMENTS.md)에서 찾습니다.

현재 작업의 범위·상태는 [0.11.0 통합 계획](plans/0.11.0-integration.md), 기여와 커밋 형식은 [CONTRIBUTING](../CONTRIBUTING.md), 라이선스는 [LICENSE-SCOPE](../LICENSE-SCOPE.md)를 확인하세요.

이 저장소의 `docs/`는 Pages 생성 산출물이므로 상세 Markdown은 `documentation/`에 분리합니다. 과거 tarball·manifest·Git 기록은 보존합니다.
