## 완료 기준

- Vue 3용 `solyi-ui`, 기존 `@solyi/core`, S 컴포넌트 이름을 구분합니다.
- 현재 import·타입·스타일·AI 지침·설치 안내와 실제 tarball 소비를 일치시킵니다.
- 선택 행의 inset과 클릭 영역은 Core의 선택적 `.sol-choice-row`가 담당합니다. 일반 체크박스와 카드형 라디오는 여백을 중복 적용하지 않습니다.
- 헤더 외형 변경은 문서 DOM·경로·탭·입력·스크롤을 유지합니다. 밀도는 현재 상태를 표시하는 스왑 버튼, 모드는 아이콘과 Dark/Light입니다.
- 컴포넌트는 Examples 기본/API 숨김 탭, 즉시 실행 화면, 바로 아래 접힌 샘플 코드를 제공합니다. 직접 링크·히스토리·키보드를 유지합니다.
- 소스·자동 검사와 실제 Chrome 화면 검수를 구분합니다. 실기기 Fold·Safari·화면 낭독기는 검증한 것으로 표시하지 않습니다.
