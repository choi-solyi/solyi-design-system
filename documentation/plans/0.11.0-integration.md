# 0.11.0 통합 작업 계획

사용자가 승인한 1~7단계를 한 배치로 구현하고 마지막에 실제 소비 앱·화면·회귀·배포를 검증합니다. 기준 커밋은 `0943713b4bee500250ebb7a927b3f1d714936f20`입니다.

## 파일 소유권과 의존성

- 폼 담당: `packages/vue-ui/src/`의 SForm·검증·메서드와 SContainer/SRow/SCol.
- 샘플 담당: 두 소비 앱, Vue 자동 import, Prism과 공통 코드 강조. 새 폼 계약이 확정되면 샘플 refs와 검증을 연결합니다.
- 문서 담당: 사이트 메뉴·검색·기존 링크 대응, 컴포넌트별 Examples/API와 실제 소스 계약.
- 가이드 담당: 루트 Markdown 정리와 한국어 현행 설명, 기여·라이선스 안내. `docs/`는 Pages 산출물이므로 저장소 가이드는 `documentation/` 아래에 둡니다.
- 통합 담당: 현재 권장 배포 쌍, allowlist·생성·버전, 마지막 소비 앱 및 실제 화면 검증과 한 번의 배포.

## 단계별 완료표

- [ ] 1. Getting started / Style / Components / Patterns / Releases / Licensing, 연속 본문과 기존 앵커 대응
- [ ] 2. Vue preset 자동 import·타입·lint 연동, 실제 두 소비 앱, Vuetify 기반 레이아웃 3종
- [ ] 3. SForm과 공통 rules·서버 오류·접근성, 입력 메서드, refs 기반 샘플
- [ ] 4. Prism의 실제 Vue SFC 혼합 문법, 라이트·다크, 원본 복사·모바일 스크롤
- [ ] 5. 모든 공개 컴포넌트의 샘플과 실제 Props / Slots / Events / Methods 일치 검사
- [ ] 6. 현재 권장 Core/UI 설치 쌍만 표시, 가이드 재배치·한국어 현행 안내·라이선스
- [ ] 7. 독립 소비 앱·타입·빌드·회귀, PC·333px·720px 라이트·다크 실제 화면 검수, CI·공개 파일 일치

2·4·6단계의 구현과 빠른 검사가 끝나면 체크포인트를 보고합니다. 최종 검수 전 항목을 완료로 표시하지 않습니다. npm 게시·1.0.0·과거 릴리스/Git 기록 삭제·새 자격증명·다른 앱 변경은 제외합니다. 커밋은 `type: 한글 제목`과 한글 불릿 본문을 사용합니다.

## 확인한 중간 결과

- 2·3단계: SForm과 원본 Vuetify 레이아웃 별칭 3종, 입력 공통 검증·메서드가 소스 타입 검사와 관련 런타임 검사를 통과했습니다. Vue preset의 실제 import 삽입, 두 앱의 타입·lint globals, 실제 lint 및 잘못된 이름·전역 재할당 실패 사례를 확인했습니다. 새 tarball 소비 검사는 최종 통합에 남아 있습니다.
- 4단계: 실제 Prism의 Vue template·TypeScript·style 혼합 문법과 30개 정본 예제의 원문 보존, 세 테마 라이트·다크 코드 전경 대비 검사를 통과했습니다. 실제 렌더링 검수는 최종 통합에 남아 있습니다.
- 6단계: 상세 문서 이동·현행 한국어 안내·MIT와 브랜드/제삼자 라이선스 범위를 정리했습니다. 저장소 Markdown 49개와 상대 링크 183개의 검사에 통과했습니다. 이전 tarball·manifest·Git 기록은 보존합니다.
- 자체 리뷰에서 날짜·숫자 초안의 이전 모델 검증 가능성, 라디오 초점 대상, submit의 native 검증 중복을 수정하고 관련 검사를 다시 통과했습니다. 새 메뉴·API 문서의 최종 계약 및 공개 배포는 아직 검증 전입니다.
