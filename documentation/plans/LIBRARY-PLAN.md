# 라이브러리화 1단계

> 이 문서는 이전 단계의 계획·전환 이력입니다. 당시 체크포인트와 문구를 보존하므로 현재 구현·공개·검수 상태와 혼동하지 마세요. 현재 작업 범위는 [0.11.0 통합 계획](../plans/0.11.0-integration.md), 실제 사용법은 [처음 시작하기](../guide/GETTING-STARTED.md)를 따릅니다.

## 이력 부록 · 당시 기록 원문

기준: 0f9daed / v0.2.5. 대상은 이 저장소와 기존 Pages 데모뿐입니다.
아페·개인 홈페이지는 연결하지 않습니다. 레지스트리 게시·새 인증·비용·지속 권한 확대는 하지 않습니다.

1. [x] 현황·계약: Vue 3.5.44 / Vuetify 4.3.0 / Vite 8.3.4, 기존 starter와 공식 library-mode 지침 조사.
2. [x] `@solyi/core`: 기존 토큰/JSON·CSS 원본의 재사용 패키지. `@solyi/vue-ui`: Button/Field/Dialog/Table과 타입·스타일 exports. Vue/Vuetify 외부화.
3. [x] npm pack → 별도 소비 프로젝트에 tarball 설치 → exports/CSS/타입/동작/빌드 검사. 미게시 private 패키지로 유지.
4. [x] 기존 starter 데모를 실제 패키지 소비로 전환. 아직 전환하지 않은 문서 예시 구분, 고정 버전·릴리스·롤백 문서.
5. [x] 로컬 자체 리뷰·기존 회귀·실제 Chrome/테마/모바일/초점, 검증에 의존하는 CI 구조 준비. 원격 CI/실패 게이트·Pages 결과는 게시 후 보고.

## 추가 승인된 UX — 같은 배포에 통합

6. [x] 다중 필드 오류 요약/필드 이동/수정 갱신, 가상 앱404와 복구.
7. [x] 가상 일괄 작업 부분 실패/실패만 재시도, 비동기 자동완성 로딩/빈/오류/응답 경합.
8. [x] 날짜·파일·자동완성·차트·트리 개별 앵커 목차. 상위별 연속 본문과 이전 링크 보존.
9. [x] Time: 단일 HH:mm 입력+작은 시/분 팝오버, 기존 값/범위/step·직접 입력·키보드/닫기/초점 계약.
10. [x] 새 UX 회귀와 패키지 소비 데모의 로컬 통합 리뷰. 이 기록을 커밋한 뒤 기존 Pages에 한 번 게시하고 실제 결과를 보고.

패키지 후보의 최초 버전은 0.1.0이며 문서 사이트 버전과 독립입니다. 이 단계는 전체 문서 컴포넌트의 라이브러리 전환이 아닙니다.
자동 변경 대상은 이 저장소의 데모만입니다. 다른 프로젝트의 버전 업데이트/테스트/배포는 후속 설계만 기록합니다.

게시 후 검증 순서: 원격 validate → deploy 성공 → verify_failure 시험의 deploy skipped → 공개32개 자산 HTTP/SHA 및 실제 화면. 이 파일은 게시 전 기록이며 실행 번호·커밋·검증 결과는 최종 보고에 남깁니다.
